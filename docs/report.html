3. คู่มือการใช้งานทุกๆ เส้น API (API Documentation)

หมวดที่ 1: จัดการข้อมูลลูกค้า (Customers)

GET /customers - แสดงข้อมูลลูกค้าทุกคน

Response: 200 OK
{
  "total": 25,
  "data": [
    {
      "id": 1,
      "first_name": "สมชาย",
      "last_name": "สายลุย",
      "phone": "0810010001",
      "address": "หอพักกัลปพฤกษ์ ห้อง 201",
      "latitude": "16.2465000",
      "longitude": "103.2520000"
    }
  ]
}

GET /customers?search={คำค้นหา} - ค้นหาจากส่วนหนึ่งของชื่อ หรือ นามสกุล

Query Parameter: search=สม
Response: 200 OK แสดงรายชื่อที่ชื่อหรือนามสกุลมีคำว่า "สม"

GET /customers/nearby?lat={lat}&lng={lng}&radius=1 - ค้นหาลูกค้าทั้งหมดในระยะ 1 กิโลเมตร

ตัวอย่าง: /customers/nearby?lat=16.2465&lng=103.2520&radius=1
คำนวณระยะทางด้วยสูตร Haversine ส่งค่า distance_km เรียงลำดับจากใกล้ไปไกล

POST /customers - เพิ่มข้อมูลลูกค้าใหม่

Body (JSON):
{
  "first_name": "กานต์",
  "last_name": "ใจดี",
  "phone": "0899999999",
  "address": "หอพักริมมอ",
  "latitude": 16.2455,
  "longitude": 103.2505
}
Response: 201 Created

PUT /customers/:id - แก้ไขข้อมูลลูกค้า

แก้ไขข้อมูลลูกค้าตามรหัส ID
Response: 200 OK

DELETE /customers/:id - ลบข้อมูลลูกค้า

ลบข้อมูลลูกค้ารายคนออกจากระบบ
Response: 200 OK

หมวดที่ 2: จัดการรายการสั่งซื้อ (Orders)

POST /orders/simulate - จำลองรายการสั่งซื้อ 20-30 รายการ (โจทย์ข้อ 3.1)

Body (Optional): { "count": 25 }
Response: 201 Created
{
  "message": "จำลองรายการสั่งซื้อสำเร็จจำนวน 25 รายการ",
  "simulated_count": 25
}

DELETE /orders/simulate/all - ล้าง (ลบทั้งหมด) รายการสั่งซื้อที่จำลอง (โจทย์ข้อ 3.2)

Response: 200 OK
{
  "message": "ล้างรายการสั่งซื้อที่จำลองทั้งหมดเรียบร้อยแล้ว",
  "deleted_count": 25
}

GET /orders/nearby?lat={lat}&lng={lng}&radius=2 - แสดงรายการสั่งซื้อในระยะ 2 กิโลเมตร (โจทย์ข้อ 3.3)

ตัวอย่าง: /orders/nearby?lat=16.2465&lng=103.2520&radius=2
แสดงรายการสั่งซื้อพร้อม JOIN ข้อมูลลูกค้า และคำนวณระยะทางไม่เกิน 2 กิโลเมตร

GET /orders - แสดงรายการสั่งซื้อทั้งหมด

Response: 200 OK แสดงรายการสั่งซื้อพร้อมข้อมูลลูกค้าครบถ้วน

PUT /orders/:id - แก้ไขจำนวนกล่อง/รายการสั่งซื้อ (โจทย์ข้อ 3.1.3)

Body (JSON):
{
  "box_count": 3,
  "note": "เปลี่ยนเป็น 3 กล่อง"
}
Response: 200 OK

DELETE /orders/:id - ลบรายการสั่งซื้อรายอัน

Response: 200 OK
